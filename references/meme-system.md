# Meme Card System

## Card Schema

Every card must contain:

```text
【卡名】
触发：
效果：
代价：
克制：
事实标签：
```

The best cards sound like a crypto trading interface crossed with a morality play. The joke should expose a mechanism, not attack a person's body, family, gender, sexuality, or private suffering.

## Core Card: 回本 Buff

```text
【亏钱自动回本 Buff】
触发：账户回撤超过心理防线，或群友开始@你。
效果：亏损立即转化为叙事。减仓叫止盈，加仓叫信仰，套牢叫长线，亏钱叫学费，最后一步是寻找下一个更热的币来“一把回本”。
代价：本金、睡眠、社交信用，以及对风险的基本感知。
克制：24小时冷启动禁令；只允许用稳定预算内的闲钱；叙事型交易需经明天的自己书面批准。
事实标签：讽刺机制，不构成投资建议。
```

## J-Node Cards

### 注意力清算

```text
【J节点·注意力清算】
触发：一篇自称虚构的私域长文冲进公共广场。
效果：小说被读者升维成卷宗；每一条反驳都被打包成新的交易确认。
代价：事实分辨率下降；未核实细节变成搜索框里的终身标签。
克制：只传播可核查事实；拒绝为标题导流。
事实标签：叙事推演。
```

### 虚构护体

```text
【虚构护体】
触发：细节开始被质疑。
效果：作者视角负责真实感，文末声明负责可退性；读者负责把两者缝合。
代价：公共讨论失去“真假”这个底层共识。
克制：先问“一手证据在哪”，再决定要不要情绪投入。
事实标签：讽刺写作机制。
```

### 形象对敲

```text
【形象对敲】
触发：一方靠争议获取注意力，另一方靠形象获得商业价值。
效果：同一则负面在两个账户上记出相反余额：前者可能增加曝光，后者承担品牌折价。
代价：被卷入的一方无论回应或沉默都要支付成本。
克制：区分公共利益与窥私消费；不给私密细节加杠杆。
事实标签：不对称传播模型。
```

## Other Archetype Cards

```text
【热搜杠杆】
触发：花钱买下一件天然自带传播量的公共道具。
效果：资产本身可以荒诞，新闻标题必须保值。
代价：注意力衰减后需要更大的荒诞补仓。
克制：问“若无热搜，这项资产的现金流是什么？”
事实标签：注意力经济讽刺。
```

```text
【叙事止损】
触发：仓位已亏，故事还在赢。
效果：把“我错了”改写为“我早知道，但时代没跟上”。
代价：认知不再更新。
克制：写下入场理由、验伪条件和复盘日期。
事实标签：行为金融讽刺。
```

## Generation Recipe

1. Pick one mechanism: heat, leverage, exit, deniability, asymmetry, or recovery psychology.
2. Give it a game-like trigger tied to a recognizable public scene.
3. Make the effect seductive for two sentences, then reveal the absurd cost.
4. Make the counter-buff boring and practical. The contrast is the joke.
5. End with the evidence label.

Keep the card under 160 Chinese characters when possible. If the user asks for a poster, keep the text even shorter and place the disclaimer outside the card frame.
