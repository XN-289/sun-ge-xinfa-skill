# 别人蒸馏了孙割写作，我蒸馏了他的回本账

昨晚，全网都在传孙宇晨那篇“我的女友景甜”。很快，有人把它蒸馏成了「孙割写作 skill」：白描、数字锚定、物件 callback、冷静短句。那个方向很好玩，但它只蒸馏到了皮。

孙割文章真正吓人的地方，不是“写得多像文学”，而是账本结构：

> 一笔钱花出去，看起来是情绪，实际可能是仓位；看起来是赠与，实际可能是期权；看起来是失败，实际可能还留下叙事、热度和退出流动性。

所以我做了另一个 skill：**孙割心法**。它不教你 impersonate 孙宇晨，也不生成伤害任何人的小作文。它做的是把热点、项目、公关事件和商业谈判，拆成一张冷冰冰的 **Recoverable-Cost Model** 回收表。

一句话：孙割写作 skill 学他的句式；孙割心法 skill 拆他的账。

## J 节点：小作文注意力清算

我把景甜这篇称为 `J节点`，因为它不是普通娱乐瓜，而是一次注意力清算的完整样本。

先说证据边界：原文由孙宇晨的一手 GitHub 仓库发布，文末自称虚构；文内关系、资金、私域细节并没有被独立核验。以下是把文本当作公共传播样本做的叙事分析，不是事实判决。

### 1. 虚构声明是退出流动性

一篇自称虚构的长文，为什么全网按卷宗读？

因为它同时给了读者两种资产：真实姓名和亲密细节负责真实感，文末虚构声明负责可退性。读者自己完成升维，把小说读成证据。

这时对方会掉进回应困境：

- 沉默，搜索框里的版本继续扩散。
- 澄清一个细节，围观者马上追问其他细节是否为真。
- 走法律程序，又制造一轮头条。

这不是事实层面的胜利，而是结构层面的主动：越难回应的文本，传播阻力越低。

### 2. 形象资产负债表不对称

同一个负面事件，记在不同人账上，余额方向完全相反。

一方本来长期活在“吃干抹净”的 meme 里，争议的边际信用成本很低；热度越高，项目、叙事、二创和注意力库存越活跃。

另一方靠公众形象、品牌信任和商业代言吃饭。未经核实的负面叙事会直接攻击资产端：品牌方会评估风险，平台会评估舆情，未来合作会重新定价。

所以这不是势均力敌的辩论，而是两种商业模式被同一个事件清算。

### 3. 大额资金是叙事期权

文内反复出现的大额数字，先不要当流水核验，先看成叙事锚点。它的作用是把读者从“爱不爱”拉回“值不值”。

孙模型的问题从来不是“这笔钱大不大”，而是：

- 成功时，这笔钱能不能变成庆功叙事、身份资产、项目故事？
- 失败时，这笔钱能不能变成委屈、反差、复仇爽文和流量库存？
- 争议时，谁承担形象折价，谁收集转发？

如果一笔支出在赢和输两个剧本里都有可回收资产，它就不再是普通消费，而是期权。

### 4. 为什么大钱也可能只是小钱

文内的具体金额，先按叙事数字处理，不按已核验流水处理。但孙模型会继续问：这笔钱对谁的资产负债表有意义？

对一个全民知名度的公众人物来说，真正的长期资产不是账户上某笔钱，而是：

- 代言信任和品牌风险溢价；
- 角色选择权；
- 公众好感带来的议价能力；
- 未来多年商业合作的可能性。

一旦未经核实的负面叙事进入搜索框，品牌方第一反应往往不是分辨真假，而是重估风险。哪怕最后事实澄清，澄清的传播半径也常常小于原始指控。

所以三千万这个数字真正刺眼的地方，不在“多不多”，而在它可能不足以覆盖整条未来商业生命周期的折价。这不是说某个结果必然发生，而是说：**形象资产的回撤，往往比现金资产的到账更快。**

### 5. 热度就是储备货币

巴菲特午餐、天价香蕉、BitTorrent 收购，这些事在普通财务表里是怪账，在注意力表里可能是采购。

孙模型不问“花钱好不好看”，只问：

- 新闻标题能不能传？
- 能不能变成后续故事的信用背书？
- 争议能不能带来搜索、转发、二创和社群讨论？
- 最终由谁把注意力接成现金、合作或议价权？

没有证据证明某个具体账户赚了多少，不能乱说。但机制可以拆清楚：注意力是中间货币，最终要么变现，要么清算别人的信用。

## Skill 输出样例

安装后只需要一句话：

```text
使用 $sun-ge-xinfa，把景甜小作文当成 J 节点，输出注意力清算表和防割清单。
```

它会先分层，再给结论：

| 六问审计 | J 节点判读 |
|---|---|
| 现金流向 | 文内大额支出与资金冲突是叙事锚点；真实性未核验 |
| 回收形态 | 注意力、叙事控制权、二创流量、后续讨论素材 |
| 回收时间 | 发布即期回收；争议周期内持续产生 remix |
| 失败出口 | “虚构”降低证伪压力；解释、否认和诉讼都可能续热度 |
| 成本归属 | 被点名者承担形象与回应成本；公众承担事实噪音 |
| 信用燃烧 | 极高；短期流量强，长期事实分辨率被消耗 |

结论：**注意力强回收，事实弱回收，长期信用高风险。**

它还会给一张梗卡：

```text
【J节点·注意力清算】
触发：一篇自称虚构的私域长文冲进公共广场。
效果：小说被读者升维成卷宗；每一条反驳都被打包成新的交易确认。
代价：事实分辨率下降；未核实细节变成搜索框里的终身标签。
克制：只传播可核查事实；拒绝为标题导流。
事实标签：叙事推演。
```

## 为什么值得装

这个 skill 的价值不是让你更坏，而是让你别做成本归属那一栏。

它能拆四类事：

1. **热点事件**：事实、指控、网传、叙事推演分层，不把瓜当证据。
2. **项目叙事**：热度、解锁、退出、信用燃烧和风险承担放在同一张表。
3. **商业谈判**：对方要现金、地位、安全、速度还是确定性；你能用什么结构扩大价值。
4. **亏钱复盘**：识别“回本 Buff”，先关杠杆，再写验伪条件，24 小时后再谈故事。
